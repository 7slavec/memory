## Ресурсы

- Оригинальные шесть SVG из Figma сохранены в Asset Catalog, размеры 24×24 и 16×16. Используется template tint; прозрачность значка «Без срока» содержится в самом SVG, не применяется второй раз.
- Собственные цвета Figma — отдельные named color sets, Light/Dark, не глобальная замена MemoryTheme.
- Шрифты Inter и Instrument Sans из официального [Google Fonts repository](https://github.com/google/fonts), папки `ofl/inter` и `ofl/instrumentsans`. Оригинальные лицензии OFL включены в ресурсы. Регистрация локальная, один раз за процесс. Custom fonts используют relativeTo для масштабирования на iPhone.

## Проверка

- `FigmaRecordsTests` проверяет наличие шрифтов/иконок и создаёт PNG карточек для светлой/тёмной темы, ширин 320/393/652 и увеличенного текста. Это визуальные артефакты, не golden snapshots.
- `--uitest-records-design` использует существующий DEBUG-only тестовый host: in-memory база, отключённый облачный клиент, пропущены аккаунт/первичный вход. В Release флаг выключен.
- `testFigmaRecordsPreserveSearchEditAndComplete`: поиск, открытие/возврат, независимое выполнение с hit target 44 pt, сохранение соседнего события.
- `scripts/verify-local.sh --ui` запускает регрессию Mac и компиляцию iOS. Проверка реального устройства и установка — отдельные действия, не подразумеваются успешным билдом.
