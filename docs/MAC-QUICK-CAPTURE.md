# Быстрый ввод Mac — 30.09.2026

## Поведение

- ⌃⌥N открывает текст, ⌃⌥Пробел начинает диктовку. Профиль → Быстрый ввод
  и стандартные Settings используют одну страницу: смена/отключение сочетания,
  сетка девяти положений 3×3. Сочетания и положение локальны для Mac.
- Работает, пока процесс Norka запущен, в том числе без главного окна.
  Автозапуск, фоновые разрешения и постоянная плавающая кнопка не добавлены.
- Одна nonactivating NSPanel, уровень floating, текущий экран по указателю,
  visibleFrame без Dock/меню. Главное окно и его редактор не переключаются.
  Повторный вызов возвращает ту же панель, а не создаёт новый черновик.
- Появление/скрытие: только opacity, `MemoryMotion.panelDuration`, без движения
  всей страницы или бесконечной анимации. Общие Flow-цвета, кнопки и скругления.
- Escape/верхний крестик скрывают панель, останавливают микрофон без отправки,
  оставляют текст и редактор/review в памяти до выхода из приложения.
  При смене аккаунта панель очищается, чтобы не переносить чужой черновик.
- Текстовый виджет 360×52 pt, расширяется по высоте до шести строк; Enter сохраняет.
  Без логотипа, ведущей стрелки отправки и лишней шапки. Стрелка также убрана
  из основного поля ввода Mac; iPhone-компоновка не меняется.
  Ошибка не очищает текст.
  Распознавание использует существующий локальный/удалённый pipeline и настройки.
- Голос — небольшая поверхность шириной 264 pt: общая `GlassVoiceOrb`, состояние
  слушания/обработки, прокручиваемая транскрипция. Кнопка клавиатуры возвращает
  распознанный текст в поле. Пустой результат предлагает повторить, не исчезает.
- Валидные результаты автоматически сохраняются одной транзакцией
  `VoiceBatchPersistence` вместе со связями, как на главном экране. Неоднозначные
  остаются в review до исправления. Сохранённые карточки можно открыть и изменить
  в той же панели (440 pt), затем вернуться. Главное окно не затрагивается.
- Один результат показывает «Изменить» и отмену создания; скрывается через 3 секунды
  без взаимодействия. Наведение приостанавливает таймер, Tab/редактор оставляют
  результат до явного закрытия; ошибки и VoiceOver блокируют автоскрытие.
  Несколько результатов никогда не исчезают по таймеру: доступны карточки, новая
  запись, отмена создания всей группы и закрытие. Повторный вызов одиночного
  результата начинает новый ввод; незаконченные редактор и группа сохраняются.
- После сохранения запускаются существующие синхронизация и планировщик.
  Неуспех уведомления отдельно сообщает, что сама запись сохранена.
- `MacCaptureReminderQueue` последовательно обрабатывает изменения уведомлений
  одной записи; быстрая отмена создания должна побеждать отложенный запрос разрешения.

## Владельцы

- `Features/Capture/MacCaptureShortcut`: Carbon-регистрация двух конкретных
  сочетаний; никаких глобальных мониторов ввода. Проверяются дубликаты, системные
  сочетания и результат регистрации; конфликт не удаляет прежнее сочетание.
- `Features/Profile/MacQuickCaptureSettings`: запись клавиш только сфокусированным
  NSView; глобальные сочетания временно снимаются на время назначения и возвращаются
  при завершении/отмене/уходе из окна. Поддерживаются буквы, цифры, пробел и минимум
  два модификатора, один из которых Control/Option. Используются физические клавиши.
- `MacQuickCaptureController`: жизненный цикл, размещение, фокус, команда активации.
- `MacQuickCaptureView`: отдельный несохраняющий автоматически ModelContext общего
  контейнера, draft/review, сохранение; rollback не затрагивает редактор главного окна.
- `QuickCaptureCard` принимает `CaptureActivation`, не меняющий identity компонента.
- `VoiceInputController`: один активный микрофон между окнами; поколение запроса
  отсеивает поздние разрешения и callback старой диктовки после отмены.

## Проверка и ограничения

- Release Mac/iOS собраны; мини-виджет установлен в `/Applications/Norka.app`,
  подпись проверена, запуск подтверждён. iPhone не переустанавливался.
- Восемь точечных unit-тестов прошли: валидность/различие default shortcuts; дубликат и сохранение
  прежнего значения; отключение и перезапуск настроек; размещение на экране с
  отрицательными координатами; отмена во время разрешений не запускает микрофон;
  повторный старт/второе окно не запрашивают его дважды; девять якорей при смене
  размера; защита автоскрытия при взаимодействии, ошибке и VoiceOver. Разрешения в тестах подменены,
  реальное аудио не записывалось. Это не тест физического нажатия.
- Mac, тёмная системная тема: через UI подтверждены сетка девяти положений,
  открытие мини-поля из настроек и немедленный фокус. Визуально виден голосовой
  виджет со сферой и транскрипцией; текущая пользовательская диктовка оставлена
  без вмешательства. Это не проверка качества распознавания/сохранения.
- Два новых изолированных UI-теста добавлены (одна запись → редактор → отмена;
  группа → редактор → список → отмена), но не прошли: стенд не получил главное
  окно тестового процесса даже после команды открытия. До сохранения не дошли;
  не считать эти сценарии проверенными. Ручная проверка установленного Release
  при этом смогла открыть виджет. Повторный полный UI-прогон не выполнялся.
- Пользователь подтвердил, что предыдущий глобальный ввод работает; претензия
  относилась к размеру и сценарию. Сочетания не переназначались при установке.
- Живой микрофон/разрешения, fullscreen/несколько мониторов, светлая тема и доставка
  новых записей на второе устройство требуют пользовательской проверки.
- Отмена создания удаляет только записи текущего результата и их связи через
  существующую soft-delete транзакцию. Черновик не переживает завершение процесса.
- Исходная точка отката мини-виджета: `44b7c93`; копия прежней установленной сборки
  в папке задачи `backups/Norka-before-mini-widget-20260930.app`.
  Более ранняя копия до глобального ввода: `backups/Norka-before-quick-capture-20260930.app`.
  Данные не откатывать.
