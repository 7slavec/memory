# Голосовые связи · 28.09.2026

## Контракт

- Одна фраза по-прежнему даёт 1–6 записей. Дополнительного запроса к модели нет.
- Необязательный `linkGroups`: индексы entries с нуля, confidence=high, дословная evidence из речи. Модель предлагает группы только при явной общей цели или просьбе связать, не по одинаковой дате/теме или слову «потом».
- Сервер и клиент проверяют диапазоны, повторы, цитату и уверенность. Пересекающиеся группы отклоняются целиком. Ошибочные необязательные метаданные не отменяют сами записи.
- Старый сервер и локальный fallback продолжают создавать записи без автоматических связей. Существующие записи автоматически не подбираются.
- Новые Item и RecordLink сохраняются одной транзакцией (`VoiceBatchPersistence`). Повторное «Готово»/сохранение правок не создаёт заново снятые связи.
- Общая группа, круглые значки, редактор и попап — существующие компоненты. В review черновик отделён от сохранённого экземпляра, которым управляет попап связей. Переход к другим записям сохраняет обычную защиту несохранённого ввода.
- Отмена голосовой пачки удаляет только её записи (tombstones), снимает их связи, сохраняет оставшихся участников и отменяет уведомления. Исключение из группы не удаляет запись.
- Нет зависимостей выполнения, относительных сроков, автоматического переноса дат или геолокации.

## Voice Lab

Сверху «Локальный разбор»: процент точного совпадения заголовка, описания, даты и всех трёх одновременно, затем число примеров. При пустом наборе — прочерк, не 0/100%. Это не процент обучения и не измеренная точность DeepSeek/распознавания аудио. Статистика вычисляется при изменении набора, не при каждом переключении настройки.

Ниже прежние DeepSeek / Уточнения / Мои примеры. Последний переключатель явно сообщает об отправке исправлений как примеров в облачный запрос; самопроизвольно не включается. Веса модели не обучаются. Ручной ввод и список примеров скрыты, `VoiceLabStore` и автоматический сбор исправлений не удалены. Данные статистики локальные для устройства.

## Проверки без пользовательских данных

- `MemoryTests/VoiceLinkTests`: метаданные, совместимость, независимые группы, сохранение/отмена, удаление участника, откат, пустая статистика.
- `MemoryUITests/testVoiceReviewUsesOnePageAndReturnsFromEachRecord`: группа → попап → редактор → снять связь → список → изменить запись.
- `node --experimental-strip-types supabase/functions/interpret-voice/link-groups.test.mts`: проверки серверной валидации.
- Два контрольных высказывания после разрешённого развёртывания: «В пятницу в семь вебинар, завтра до обеда отправить заявку, чтобы попасть на этот вебинар» (2 связанных); «Завтра в девять оплатить интернет и в десять позвонить маме» (2 независимых).

Механические проверки не доказывают качество смыслового решения модели. Нужна отдельная небольшая проверка реальных ответов после публикации. Синхронизацию группы между устройствами, конфликты offline и латентность облака нельзя считать проверенными по сборке.
